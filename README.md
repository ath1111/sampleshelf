# SampleShelf

A web app for organizing audio samples. Upload, tag, search,
and preview your sounds in one place instead of digging through folders.

## Planned features
- Upload samples with metadata (BPM, key, type, tags)
- Search and filter by tag, BPM, key, or category
- Preview audio in the browser
- User accounts with personal libraries

## Tech stack
Node.js, PostgreSQL, Prisma, Tailwind CSS, Docker

## Status
In early development.
